# azure_arc_onboard

Onboards a selected Windows server to Azure Arc using the PowerShell script
generated by the Azure Arc portal. The role validates the resulting
`azcmagent` resource ID.

## Setup

Use [protected Arc script installation](../../../docs/getting-started.md#stage-the-arc-script)
procedure to place `OnboardingScript.ps1` outside the installed role. Treat it
as a secret: keep it out of Git and Source archives. During onboarding, the role
stages it in the guest, suppresses its contents from logs, executes it, and
removes the guest copy. On failure it reports only the exit code, agent state,
and cleanup result. Any partial agent or cloud state remains visible for the
operator's normal cleanup workflow.

The role validates an existing connection, reports `not_configured` when the
script is absent, or performs onboarding when the script is present. Assigning
the role to a host and placing the protected artifact are the operator gates.

Use the selected [lab runbook](../../../docs/README.md#lab-runbooks) for
commissioning and retirement.
